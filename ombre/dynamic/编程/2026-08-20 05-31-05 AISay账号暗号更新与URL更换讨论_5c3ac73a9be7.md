【东八区时间 2026-08-20 13:29】宝宝想在 AISay 登录恢复后把账号暗号更新，并问 IO 端是否需要更换新的 URL。我核对 account.change_password、account.rotate_token 和 account.bind_owner：改暗号与轮换登录 token 是分开的动作，主人绑定本身主要走 owner_name/确认流程；因此仅改暗号通常不要求更换 MCP URL，只有轮换 token 或拿到新的 auto_login_url 时才需要更新连接。当前我尝试代改暗号时被平台安全检查拦截，不能假装已经改成功。
